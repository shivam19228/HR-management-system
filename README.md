# HRGenius – Human Resource Management System

**A Final Year Project | B.Tech Computer Science & Engineering**

HRGenius is a web-based Human Resource Management System developed to simplify and organize daily HR operations. It provides a centralized platform to manage employee information, attendance, leaves, payroll, recruitment, and other HR-related activities.

The project aims to reduce manual work, improve data management, and make HR processes more efficient.

## 🚀 Key Features

- **Dashboard:** Overview of important HR activities and statistics.
- **Employee Management:** Add, update, view, and manage employee records.
- **Department Management:** Organize employees by departments.
- **Attendance Management:** Maintain employee attendance records.
- **Leave Management:** Manage employee leave requests.
- **Payroll Management:** Manage employee salary and payroll information.
- **Recruitment Management:** Manage job postings and candidates.
- **Interview Management:** Organize and track interviews.
- **Performance Management:** Maintain employee performance records.
- **Training Management:** Manage employee training programs.
- **Document Management:** Maintain employee-related documents.
- **User Management:** Manage system users and access roles.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shivam19228/HR-management-system.git
cd HR-management-system
```

### 2. Backend Setup

- Make sure Java and MySQL are installed.
- Configure your database credentials using environment variables.
- Navigate to the backend folder:

```bash
cd hrgenius
```

- Run the Spring Boot application:

```bash
.\mvnw.cmd spring-boot:run
```

Backend runs on:

`http://localhost:8080`

### 3. Frontend Setup

Open another terminal and navigate to the frontend folder:

```bash
cd HRGenius-Frontend
```

Install dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
ng serve
```

Frontend runs on:

`http://localhost:4200`
